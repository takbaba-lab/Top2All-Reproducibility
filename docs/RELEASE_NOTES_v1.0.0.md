Initial public reproducibility release accompanying the Top2All manuscript.

- Includes training, prediction, evaluation and plotting code, metadata, validation folds, figures, source tables and a provenance-linked registry.
- Exact curated inputs, formal predictions and detailed evaluation assets are provided separately in the Zenodo core archive.
- Zenodo DOI: https://doi.org/10.5281/zenodo.23361275
- Raw/source RNA-seq data: DDBJ DRA015952.
- The 174 project-trained checkpoints (~23.9 GB) are not included in the core archive and may be distributed separately if needed.

The Zenodo DOI is reserved; deposit publication is controlled by the authors. The
core archive contains 846 files (848,696,315 uncompressed bytes), with SHA-256
`26446ed0b8bb8913ee745047855464cc53a112b468514160039fda69e280f4c3`.

The original raw-read-to-curated-matrix workflow and original run-bound complete
software lockfile remain unavailable, as documented in the reproduction guide.
